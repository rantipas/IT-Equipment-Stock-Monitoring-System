Designed and developed a centralized web-based dashboard to monitor real-time stock levels of IT infrastructure and office consumables. The system serves as a critical reporting tool, bridging the gap between legacy enterprise databases and end-user visibility, ensuring accurate tracking of high-value technical assets. Core Functionalities: Asset & Consumable Segmentation: Engineered distinct reporting modules to separate Fixed IT Assets (Computers, Broadcasting Equipment) from Consumables (toners, accessories), using specialized SQL logic to handle the different tracking requirements of each inventory type. Dynamic Inventory Categorization: Developed an automated filtering system that parses complex database hierarchies (e.g., "/Information Technology/Computer Equipment/") to group assets by model and nature, dynamically generating status tables based on live stock counts. Real-Time Stock Visualization: Implemented a responsive dashboard that directly queries production data to display instant quantity availability (Qty), providing immediate insight into stock shortages or surplus without manual data entry. Hybrid Database Architecture: Built a secure backend that integrates two distinct database technologies simultaneously: a local MySQL database for managing secure user authentication and sessions, and a remote Microsoft SQL Server (MSSQL) connection for fetching enterprise-level inventory data.
